# Form spec: Camp Crew Member Indemnity / Media Release

Source paper form: "CAMP CREW MEMBER/INDEMNITY/MEDIA RELEASE".
Filled by: crew member, before camp.
Maps to: consent_records (Tier 2, append-only, never deletable), linked to crew, not camper.
Form wins over the brief. No em dashes.

## Fields
- Full name and surname
- ID number
- Indemnity acknowledgement (boolean: holds harmless organisers, sponsors, venue)
- Media release: photo / video consent (boolean, can be DECLINED independently; if
  declined, crew still welcome, no photos taken)
- POPIA acknowledgement (boolean)
- Consent to participate in activities, excursions, travel (boolean)
- Signed at (location)
- Date (day, month, year)
- Crew member name + signature
- Witness name + signature

Hard rule from the form: NO PARTICIPANT accepted to camp without a signed indemnity.
Mirror the camper consent gate: crew roster shows consent status.
